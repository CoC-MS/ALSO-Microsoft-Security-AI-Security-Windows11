# 🐛 Reporting issues

[Public documentation](README.md)

Search the [issues for the Windows 11 project](https://github.com/CoC-MS/ALSO-Microsoft-Security-AI-Security-Windows11/issues) before reporting a problem. Use its issue chooser to report a bug, documentation or licensing correction, or policy request.

Include the affected policy identifier and filename, relevant licensing or feature availability, import tool version, reproduction steps, and expected versus actual behavior.

> [!IMPORTANT]
> Public issues are visible to everyone. Do not attach tenant exports, credentials, tokens, certificates or private keys, customer details, tenant/user/device IDs, group memberships, assignments, or unredacted logs and screenshots. Provide a minimal redacted example instead.
